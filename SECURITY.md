# Security policy

## Supported versions

Security fixes are provided for the latest released version. Older releases
receive no backports; update to the current release listed in
[CHANGELOG.md](CHANGELOG.md).

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting form for this repository. Please
include reproduction steps, affected versions, and the potential impact, but do
not attach confidential source documents. Do not publish vulnerability details
in a public issue before a fix is available.

If the private form is not visible, open a public issue containing no sensitive
details and ask the maintainer to enable a private reporting channel.
