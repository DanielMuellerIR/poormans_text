# Support / Unterstützung

## English

Please use the GitHub Issues section of this repository for reproducible bugs
and focused feature requests. Include the Poor Man's Text version, macOS
version, Pandoc version, interface used (app or CLI), and the exact diagnostic.
Do not attach confidential documents; create the smallest non-sensitive sample
that reproduces the problem.

## Deutsch

Für reproduzierbare Fehler und konkrete Funktionswünsche bitte den
GitHub-Issues-Bereich dieses Repositories verwenden. Benötigt werden die Version
von Poor Man's Text, macOS und Pandoc, die verwendete Oberfläche (App oder CLI)
sowie die genaue Diagnose. Vertrauliche Dokumente nicht anhängen; stattdessen
eine möglichst kleine, unkritische Beispieldatei erstellen, die den Fehler
auslöst.
