# Herkunft der Probeausgaben

[bereits fixierten Korpus](../P11-NATURAL-EVIDENCE/ATTRIBUTION.md). Die
hier gespeicherten Markdown-/JSON-Ausgaben sind abgeleitete Testbelege; die
ursprünglichen Text-/Bildlizenzen und Attributionen gelten weiter. Die
synthetische Tabelle stammt aus dem eigenen PMT-Fixturegenerator. Es liegen
keine Modellgewichte oder Softwarewheels im Repository.
