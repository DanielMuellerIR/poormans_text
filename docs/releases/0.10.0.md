Import presentations and notebooks, control conversion from the app, and process batches with bounded parallelism.

### New formats

- Native PPTX/PPTM/POTX and ODP import preserves slide order, text, lists, tables, speaker notes and supported images. Unsupported objects and formatting losses are reported.
- IPYNB import preserves Markdown, language-tagged code, text/error outputs and embedded images. Notebook code is never executed.
- CSV/TSV, Excel macro/template variants, HTML/XHTML, Safari webarchives, EPUB, LaTeX, DocBook, Org, MediaWiki, Textile, reStructuredText, FictionBook, GIF, BMP and WebP are now supported.

### App and command line

- Import multiple files or folders. Remember output, table, OCR, frontmatter and Textbundle settings in the app, now also available in German.
- Select individual results, open or copy Markdown, preview up to 256 KiB, and retry failed inputs without replacing successful outputs. Copying reports omitted images.
- Use Finder and selected-text services, `--stdout`, `--frontmatter` and `--textbundle`.
- See file, page, sheet, slide and notebook-cell progress. Cancel running conversions safely; finished batch results remain available. External tools support `--timeout SECONDS`.
- Choose `--jobs 1` through `--jobs 4`, or the equivalent app setting. Default concurrency is one document; local OCR remains limited to one request per process. Results and destination reservations follow input order.

### PDF quality and reliability

- Choose automatic, always-on or disabled PDF OCR and local OCR languages. Mixed digital/scan pages retain their digital text and add scanned text.
- Order two-column text, optionally remove repeated headers/footers and conservatively join hyphenated words. `--pdf-layout legacy` retains the previous extraction for comparison.
- Diagnostics include available page, sheet and cell references. Batch destinations are checked against all source documents before writing; existing output is never overwritten.
- XLS detection no longer invokes Apple's Word inspector on Excel containers, avoiding a hang in `textutil`.
- Reuse verified package readers and load XLSX sheets individually. The measured large-XLSX memory peak fell by about 32%; two-document parallel runs were faster for XLSX and DOCX but used more memory. Results depend on documents and hardware.

Validated with 461 automated tests, generated document fixtures and independent content/image comparisons. Universal macOS app for Apple silicon and Intel; macOS 13 or newer. Word-processing, HTML, ebook and text-markup imports require Pandoc.
