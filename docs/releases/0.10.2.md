This update fixes content handling in PowerPoint, PDF and Jupyter Notebook imports.

- PowerPoint compatibility blocks now contribute one supported representation or its fallback, preventing duplicate slide text and image references.
- Automatic PDF OCR now detects scan images in inherited page resources, including mixed pages with a digital header and scanned body.
- Missing notebook images with spaces, escaped punctuation or parentheses in their paths receive complete placeholders and diagnostics without leaving filename fragments in the Markdown.
- Notebook error tracebacks keep their line breaks. Source code and stream output retain their existing fragment handling.

Validated with 464 automated tests and temporary document fixtures. Universal macOS app for Apple silicon and Intel; macOS 13 or newer.
