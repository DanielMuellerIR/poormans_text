Poor Man’s Text 0.16.1 adds a direct Fastra result action and improves reference and encoding handling.

- Open converted Markdown directly in Fastra, alongside the default application. Fastra must be installed; open failures receive a visible diagnostic.
- Preserve notebook attachment reference links inside blockquotes and with destinations continued on the next line.
- Leave ordinary paragraph text and malformed reference definitions unchanged.
- Read HTML charset declarations correctly when earlier quoted attributes contain greater-than characters.

The download contains a signed and notarized universal macOS app and CLI for Apple Silicon and Intel Macs. Download the SHA-256 file alongside the DMG to verify the archive.
