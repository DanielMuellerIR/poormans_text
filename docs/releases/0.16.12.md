# Poor Man’s Text 0.16.12

## Native Shortcuts conversion

Convert one document into a new Markdown folder or Textbundle with the native
**Convert Document to Markdown** action. Choose a document and destination folder,
then expand the action for metadata, spreadsheet, OCR, PDF and timeout options.
The result is a text list: the complete folder’s local file URL first, then
any conversion warnings. Use the first list item in following actions.
Existing results are never overwritten.
Pandoc is still required for the formats that use it.

The metadata build explicitly compiles the real adapter for both architectures,
including toolchains that do not emit SwiftBuild constant-value side products.
The protocol-file option is forwarded explicitly to the compiler frontend,
using the option name supported by both Swift 6.3 and newer toolchains.
Enum definitions are compared independently of their generated order, while
parameter and enum-case order remains checked. Hyphenated checkout directory
names retain the compiler package identity used by SwiftPM.
Results and warnings are returned directly without waiting for a system dialog.

## Import corrections

- Preserve emoji and other supplementary Unicode characters in RTF imports.
- Keep XLS parent-directory links and empty XLSX formula results accurate.
- Preserve OpenDocument presentation headings and nested text once, omit deleted
  master-document revisions, and recognize prefixed FictionBook documents.
- Preserve rotated PDF reading order and avoid duplicate OCR text without
  dropping equal text at a different position.
- Keep Markdown examples inside inline HTML and mixed list/quote code blocks
  literal; handle malformed nested links without repeated scans.
- Validate notebook and presentation image pixels and bound referenced image
  copies before publishing. Unpublished conversion workspaces remain private.
- Include XLSX in the Finder service’s supported file types.

A Homebrew Cask draft is included in the source repository. It has not been
submitted to Homebrew and does not provide a public tap.

## Requirements

macOS 13 or later. The universal app and bundled CLI support Apple Silicon and
Intel Macs. Source documents and existing output folders remain unchanged.
