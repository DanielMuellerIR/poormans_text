# Poor Man's Text 0.16.16

- Plain-text email bodies preserve indentation, tabs, repeated spaces and blank
  lines in fenced text blocks. Markdown, HTML and code fences within the message
  remain literal text. Mixed HTML bodies and attachments are retained.
- Notebook imports preserve literal text containing invalid nested parentheses
  in Markdown link titles, while continuing to rewrite following valid links.
  This includes the source changes from version 0.16.15, which had no binary release.

The app and disk image are signed and notarized. The bundled command-line tool
uses the same conversion engine as the app.
