# Poor Man's Text 0.16.17

This update fixes email and notebook conversions that could change literal text
or leave image attachments unresolved.

- Keep each email MIME body separate during HTML conversion. Unclosed HTML quotes,
  lists and comments no longer alter subsequent bodies; plain text keeps its
  whitespace and literal Markdown syntax.
- Preserve notebook code examples with Windows or classic Mac line endings.
- Rewrite only the valid inner link when link-like text is nested, while keeping
  supported image nesting and following links.
- Resolve image attachments with nonbreaking spaces and other Unicode spaces in
  their names.

Source documents remain unchanged. The download includes the macOS app and CLI
for Apple silicon and Intel, signed with Developer ID and notarized by Apple.
