Poor Man’s Text 0.16.2 fixes text loss in document imports and improves conversion reliability.

- Preserve quoted CSV fields, empty final records, CDATA text in ODS/XLSX/ODM, explicit OpenDocument spaces, and compressed Unicode characters in legacy Excel files.
- Read HTML image attributes accurately, retain alt-text character references, and protect literal code inside Markdown lists and blockquotes.
- Use the available PDF OCR resolution and report flattened hyperlinks in PowerPoint tables.
- Reject malformed OLE allocation tables and oversized directory streams before expanding them in memory.
- Stop background helper processes when their main process exits and keep parallel CLI progress ordered.
- Retain the selected output folder when retrying a single file after an input-enumeration failure.
