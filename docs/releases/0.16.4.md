Poor Man’s Text 0.16.4 preserves more source content and strengthens validation of imported images and spreadsheets.

- Validate embedded HTML images and extracted package media by their raster content. Reject non-image and active SVG content, and preserve valid images with incorrectly declared file types.
- Preserve literal plain-text email bodies, Markdown punctuation and indentation without turning them into lists, HTML or code blocks.
- Resolve multiline notebook image links and Markdown reference labels and titles, including escaped and character-reference resource names.
- Preserve UTF-16 characters at CSV inspection and legacy Excel continuation boundaries. Read Excel workbook streams from the compound document root.
- Keep images inside OpenDocument presentation tables, including repeated cells, and count empty spreadsheet rows toward expansion limits before allocation.
- Preserve ODS text around annotations and namespace-qualified spreadsheet attributes.
- Retain cancellation and timeout diagnostics during format detection, and prevent Pandoc installation from overlapping a conversion.
