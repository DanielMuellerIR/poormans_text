# Poor Man’s Text 0.41.19

This macOS release includes the changes since 0.41.4 and improves rich-text import and image OCR output.

- Preserve Word RTF apostrophes, font encodings and Shift-JIS characters, including escaped multibyte sequences.
- Preserve RTF text backgrounds as highlight markers, including Unicode and nested formatting. Original highlight colors are approximated and reported in diagnostics.
- Correct copied OCR text for multi-frame images.
- Share conversion logic with the developing Linux port while retaining native macOS document, PDF and OCR backends.

The source includes a Linux CLI and GTK interface, packaging tools and optional offline OCR integration. Full Linux desktop and content-quality acceptance is still pending. This release distributes the macOS app and CLI only; it includes no Linux packages or optional OCR models.

Known limits remain: OCR can omit or misread text, and structured recognition does not guarantee complete tables or diagrams. Review converted output against the source when completeness matters.

Source documents remain unchanged and existing output directories are never overwritten. Pandoc remains required for the formats listed by `poormans-text --formats`.

The download includes the macOS app and CLI for Apple silicon and Intel, signed with Developer ID and notarized by Apple. macOS 13 or newer is required; structured OCR requires macOS 26 or newer.
