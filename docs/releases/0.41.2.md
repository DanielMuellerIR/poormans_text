# Poor Man’s Text 0.41.2

This release adds local mail and note collections, reusable conversion profiles,
and more control over what is imported and how results are reviewed. It includes
all changes since the previous public release, 0.16.17.

- Import regular MBOX archives, Apple Mail export packages and bounded Evernote
  ENEX exports as complete collections. Select, search, open, copy and preview
  individual messages or notes and their local attachments.
- Paste copied RTFD, RTF, HTML or encoded images into the app, preview the result,
  save Markdown with its assets, or copy text with explicit omitted-asset notices.
- Save named conversion profiles in the app or CLI and use them in Shortcuts.
  The dedicated profile action preserves inherited settings unless explicitly
  overridden.
- Select PDF pages, workbook sheets and cell ranges, presentation slides and
  notes, or EPUB chapters. Selections stay bound to verified source contents.
- Review rendered Markdown beside verified PDF/image sources, navigate known
  source positions and save portable conversion reports with hashes and diagnostics.
- Preserve DOCX comments and accept, reject or mark text changes. Retain PDF
  comments, highlights and safe links, plus hyperlinks in presentation text,
  tables and notes.
- Opt in to structured local OCR for paragraphs, lists and tables on macOS 26+.
  Standard OCR remains the default and fallback; broader testing on natural
  scans and photos is still pending.
- Preserve supported XLSX, XLS and ODS number formats and cached values without
  evaluating formulas. Improve literal text, link handling, preview performance
  and Finder service registration, including native ENEX associations.

Source documents remain unchanged and existing output directories are never
overwritten. Collection output is saved as a complete folder or Textbundle;
`--stdout` is not available for collections. Pandoc is required for mail, ENEX
and other formats listed by `poormans-text --formats`.

The download includes the macOS app and CLI for Apple silicon and Intel, signed
with Developer ID and notarized by Apple. macOS 13 or newer is required;
structured OCR requires macOS 26 or newer.
