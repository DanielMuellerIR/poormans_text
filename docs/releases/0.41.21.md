# Poor Man’s Text 0.41.21

The macOS app can extract structured fields from invoice and delivery note PDFs with embedded text.

- Create a reusable mask for a partner and document type. Use suggested fields such as the receipt number and date, or mark a region in the PDF and name the field.
- Add test PDFs and use the arrows to preview the draft mask on each one before saving. Click a value to highlight its source. Manual value corrections apply to the individual receipt.
- Apply the same mask to a batch in the app or automate it with `poormans-text extract --mask …`. Each processed PDF gets a JSON file with its values, sources and review status. Existing output files stay protected.
- Missing and ambiguous values are exported as `null`. The batch marks them for review and the CLI provides a machine-readable run summary.

See the [English guide](https://github.com/DanielMuellerIR/poormans_text/blob/v0.41.21/README.md#extract-receipt-data-on-macos) or the [German guide](https://github.com/DanielMuellerIR/poormans_text/blob/v0.41.21/README.de.md#belegdaten-unter-macos-auslesen).

The download includes the signed and notarized macOS app and CLI for Apple silicon and Intel. macOS 13 or newer is required.
