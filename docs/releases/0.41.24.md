## Poor Man’s Text 0.41.24

This release includes the desktop app and command-line tool for macOS and Linux. Linux downloads include x86-64 DEB and Arch packages and portable TAR and ZIP archives. The macOS download is a notarized Universal DMG for macOS 13 and later.

- Open several invoices or delivery notes from one partner and use the same mask on each PDF. Check the extracted values beside the PDF, correct individual receipts and export one JSON file per receipt. The GTK app and `poormans-text extract` use the same mask format as macOS.
- The apps explain conversion settings and receipt controls in English and German tooltips. The YAML option adds source details such as title and author at the top of the Markdown file.
- macOS preserves text after older RTFD image attachment groups. Linux preserves supported local image attachments from RTFD packages produced by AppKit.

A receipt mask reads embedded PDF text. Missing and ambiguous values are exported as `null` with a review status. For scanned receipts, first add a text layer. PDF layout and OCR results depend on the platform and source. Linux can save supported PDF images as separate assets. PDF import on macOS produces text and annotations. Finder integration, Shortcuts and Sparkle updates are macOS features.

Use a published package and its matching SHA-256 checksum. See the [installation instructions and Linux dependencies](https://github.com/DanielMuellerIR/poormans_text/blob/v0.41.24/docs/LINUX-BUILD.md).
