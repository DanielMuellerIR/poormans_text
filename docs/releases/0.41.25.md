## Poor Man’s Text 0.41.25

- The macOS receipt editor stays responsive while reading PDFs and evaluating masks. Corrections belong to the exact PDF that was read. Replacing a PDF at the same path clears its old corrections the next time you open it.
- Both editors reject unsupported page numbers and oversized receipt mask files. The macOS editor hides a suggestion when a field already uses its name or rule.
- The GTK receipt editor loads only the selected page when you navigate. It also tells you when a page has more clickable words than the preview can show. You can still select any region by dragging a rectangle.
- Linux preserves local RTFD image attachments that immediately follow a formatting command.

The macOS download is a notarized Universal DMG for macOS 13 and later. Linux downloads include x86-64 DEB and Arch packages and portable TAR and ZIP archives.
