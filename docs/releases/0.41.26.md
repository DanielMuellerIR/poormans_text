## Poor Man’s Text 0.41.26

- On Linux, DOCX conversion preserves text, comments, tracked changes, and embedded images in documents affected by an XML namespace parsing error.
- On macOS, RTFD conversion reports missing or nonlocal image attachments and preserves valid attachments with accented filenames.
- The CLI returns a nonzero exit status when it cannot write its output.
- The build runs more shared conversion tests on both platforms and adds native Linux product checks to CI.

The macOS download is a notarized Universal DMG for macOS 13 and later. Linux downloads include x86-64 DEB and Arch packages and portable TAR and ZIP archives.
