# Poor Man's Text 0.5.0

This is the first public release of Poor Man's Text, a native macOS app and CLI
for converting RTF and RTFD documents into Markdown folders with separately
stored images.

## Highlights

- Converts `.rtf` and `.rtfd` through one guarded, reusable conversion core.
- Preserves document structure, links, common emphasis, lists, image order, and
  embedded image bytes where the source format permits it.
- Never changes source documents or overwrites an existing output directory.
- Provides human-readable and JSON CLI output with meaningful exit codes.
- Includes a universal CLI inside the universal macOS app and offers optional,
  consent-based CLI installation.
- Ships as a Developer-ID-signed, Apple-notarized DMG with a SHA-256 checksum.
- Uses the selected sapphire-and-amethyst app icon and the WTFPL, Version 2.

## Requirements

- macOS 13 or newer
- Pandoc installed separately, for example with `brew install pandoc`

Download both release files and verify them in the same directory before opening
the DMG:

```sh
shasum -a 256 -c Poor-Mans-Text-0.5.0.dmg.sha256
```
