# Poor Man's Text 0.5.1

This maintenance release strengthens document fidelity, conversion diagnostics,
and installation safety.

## Highlights

- Preserves RTFD paragraph boundaries while retaining explicit manual line
  breaks and CommonMark fenced code.
- Shows every conversion warning, including multiple missing attachments.
- Keeps CLI JSON error output aligned with the options actually parsed.
- Uses a format-neutral conversion engine with adapter-owned detection and
  diagnostics for RTF and RTFD inputs.
- Preserves the previous installed app at a reported rescue path if an atomic
  rollback cannot be completed.
- Avoids buffering unused external-tool output in memory.

## Requirements

- macOS 13 or newer
- Pandoc installed separately, for example with `brew install pandoc`

Download both release files and verify them in the same directory before opening
the DMG:

```sh
shasum -a 256 -c Poor-Mans-Text-0.5.1.dmg.sha256
```
