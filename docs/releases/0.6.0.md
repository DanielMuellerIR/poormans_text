# Poor Man's Text 0.6.0

This release adds three new input formats and publishes the supported formats as
a machine-readable catalog, so a host application no longer needs its own format
knowledge.

## Highlights

- Converts DOCX and ODT documents through a shared, sandboxed Pandoc adapter
  with isolated media extraction, archive budgets, traversal and symlink
  rejection, and blocked remote images.
- Converts legacy binary DOC documents through a separate macOS `textutil`
  adapter with an independent text-retention check and an explicit warning about
  unsupported OLE objects, text boxes, and macro content.
- Accepts DOCX tracked changes explicitly and reports document annotations as
  structured warnings instead of silently dropping them.
- Adds `poormans-text --formats [--json]`, which reports every readable format,
  its file extensions, whether the source is a single file or a folder package,
  and whether the external tools it needs are installed right now.
- Covers the new formats with real fixtures from independent producers, direct
  Pandoc output comparisons, media hashes, and source-integrity checks.

## Requirements

- macOS 13 or newer
- Pandoc installed separately, for example with `brew install pandoc`
  (`textutil` for DOC ships with macOS)

Download both release files and verify them in the same directory before opening
the DMG:

```sh
shasum -a 256 -c Poor-Mans-Text-0.6.0.dmg.sha256
```
