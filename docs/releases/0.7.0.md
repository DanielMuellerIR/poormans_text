# Poor Man's Text 0.7.0

This release teaches the app to update itself and collects the hardening work
that followed 0.6.0.

## Highlights

- Keeps the app up to date through Sparkle: it checks a signed update feed on
  its own and offers "Check for Updates …" in the application menu, but
  downloads and installs nothing without consent. Feed and disk image must carry
  a valid Ed25519 signature, the new version is verified before extraction, and
  no system profile is transmitted.
- Offers to install a missing Pandoc from the app, with Homebrew if it is
  present and through the official installation help otherwise, and turns down
  every entry point while that installation runs.
- Verifies every entry of a DOCX or ODT package against its ZIP directory entry
  and hands Pandoc an immutable copy, instead of the source path inspected
  earlier.
- Detects package features by XML element name, so field codes are no longer
  reported as tracked changes and external images, ODT annotations, and ODT
  tracked changes are found regardless of namespace prefix.
- Keeps indented code blocks out of the Markdown clean-up, which used to change
  their content silently.
- Produces a complete release in a single run with `./install.sh --with-dmg`, so
  the repository app, the installed app, and the app inside the disk image share
  one signed bundle.

## Updating

Version 0.6.0 and older have no updater. Install this version once by hand from
the disk image; later versions can then be installed from within the app.

## Requirements

- macOS 13 or newer
- Pandoc installed separately, for example with `brew install pandoc`
  (`textutil` for DOC ships with macOS)

Download both release files and verify them in the same directory before opening
the DMG:

```sh
shasum -a 256 -c Poor-Mans-Text-0.7.0.dmg.sha256
```
