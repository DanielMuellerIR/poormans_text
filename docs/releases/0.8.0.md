# Poor Man's Text 0.8.0

This release adds native spreadsheet and OpenDocument master-document import,
widens the supported OOXML family, and hardens conversion and installation edge
cases.

## Highlights

- Converts ODS, XLSX, and BIFF8 XLS workbooks without LibreOffice, Excel, or
  Pandoc. Sheet order and stored cell values are preserved, with a choice of GFM
  tables or reversibly escaped TSV code blocks.
- Converts ODM master documents by flattening inline text and local linked ODT
  files in source order. Unsafe, remote, missing, traversing, and
  symlink-escaping references are rejected.
- Accepts DOCM, DOTX, and DOTM after validating their OOXML content. Warnings
  make explicit that Markdown cannot retain macro or template semantics.
- Reports spreadsheet merges, missing formula results, unsupported objects, and
  legacy XLS losses instead of silently hiding them.
- Keeps a validated new app installed if the saved old bundle changes identity
  during the final installer check, while preserving the suspicious backup for
  inspection.
- Preserves additional RTF paragraph boundaries and tightens list and hard-break
  cleanup without changing escaped backslashes, binary payloads, or code.
- Uses stable image names in document order without exposing technical
  attachment-collision prefixes.

## Updating

Poor Man's Text 0.7.0 and later can install this release through the signed
Sparkle update feed. Version 0.6.0 and older must first be replaced manually by
a newer version from the disk image.

## Requirements

- macOS 13 or newer
- Pandoc installed separately for word-processing and ODM files, for example
  with `brew install pandoc` (`textutil` for DOC ships with macOS)
- No external conversion tool is needed for ODS, XLSX, or XLS

Download both release files and verify them in the same directory before opening
the DMG:

```sh
shasum -a 256 -c Poor-Mans-Text-0.8.0.dmg.sha256
```
