# Poor Man's Text 0.8.1

This release fixes silent data loss in spreadsheet and master-document
conversion, cuts memory use on large files, and hardens the install and
release path. All 21 findings of an in-depth code review were verified
against the code and resolved.

## Conversion correctness

- A shared-formula cell without a stored result is now reported instead of
  silently dropping the cell, and cells that omit the optional reference
  attribute are read correctly.
- Master documents keep text around nested annotation paragraphs, write
  manual line breaks as Markdown hard breaks, preserve explicit spaces, and
  escape flattened text so a paragraph like `# Text` stays a paragraph.
- Chartsheets no longer fail the whole workbook; they are skipped with an
  unsupported-object warning. Spreadsheet hyperlink targets are reported as
  unsupported in all three readers instead of disappearing silently.
- Modern threaded comments are recognized. The ODS reader validates the
  content hierarchy before accepting a table as a sheet.
- Package inspections decide by XML namespace, so foreign elements can
  neither trigger nor hide a warning.
- List items with inline formatting are unwrapped correctly.

## Performance

- ZIP entries are verified over the mapped archive instead of copying each
  entry, so a large package no longer needs several times its own size in
  memory.
- An XLS sheet is read only up to its own end-of-sheet record instead of
  materializing the rest of the workbook stream once per sheet.

## Install and release hardening

- The disk image and its checksum are published only after the installation
  passed its final check, and the installation is rolled back if publishing
  fails.
- The Sparkle signing key is available only to the step that signs, workflow
  actions are pinned to reviewed commit SHAs, prereleases are skipped, and a
  manual appcast run whose tag is not the latest stable release is refused.
- Debug builds keep their symbols; only the release path strips them.
