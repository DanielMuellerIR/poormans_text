# Poor Man's Text 0.8.2

This release prevents silent structure loss in master documents and
spreadsheets, and makes interrupted installs and releases transactional. All 13
findings of an in-depth code review were verified against the code and resolved.

## Document conversion

- OpenDocument master files keep inline text, notes, and linked sections in
  source order. Leading tabs and wider indentation stay literal instead of
  turning text into accidental Markdown code blocks.
- Literal GFM strikethrough and entity characters are escaped where required.
  Asset renaming touches only real Markdown image targets and leaves code spans,
  fenced or indented code blocks, escaped text, and unclosed backticks intact.
- XLSX hyperlinks retain their display text when the referenced cell is empty.
  That text is subject to the same workbook limits as cell content, and
  worksheet relationships are accepted only from the declared Office Document
  relationship namespace.
- BIFF worksheets stop at the next physical sheet and must contain their own
  end-of-file record. An ODS spreadsheet nested inside a text body is rejected,
  and foreign OPC `Override` elements cannot make an unrelated package look like
  a Word document.

## Install and release hardening

- The Sparkle appcast is generated from the requested release tag, while pinned
  build dependencies are resolved before the private signing key enters the
  signing step.
- App replacement, CLI-link publication, DMG publication, and rollback now keep
  explicit pending states across interrupt signals. Cleanup removes only files
  whose device and inode still match the files created by this run.
- A matching installation remains installed once the complete DMG and checksum
  pair is visible. Half-published or externally replaced artifacts are rejected
  without deleting an unrelated replacement.
