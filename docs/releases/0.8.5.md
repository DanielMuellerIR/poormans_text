# Poor Man's Text 0.8.5

This release adds native PDF and image import, preserves spreadsheet hyperlink
targets, and strengthens a package-reader regression test.

## PDF import

- Import PDF files with PDFKit. Output uses one visible Markdown section per
  page and keeps embedded text in page order.
- Pages with little embedded text use local Vision OCR. Password-protected,
  damaged, oversized, and over-budget PDFs are rejected before an output is
  published.

## Image import

- Import PNG, JPEG, HEIC, and TIFF files. The original image is retained byte
  for byte as an asset in the result directory.
- Local Vision OCR is on by default and can be disabled with `--image-ocr off`.
  Multi-frame TIFF files produce one OCR section per frame while retaining one
  source asset.

## Spreadsheets and package checks

- Preserve one hyperlink target per spreadsheet cell from ODS, XLSX, and XLS.
  Markdown tables render the link safely; escaped TSV blocks retain its
  Markdown source.
- Run the mapped-ZIP truncation regression in a child process so the expected
  `SIGBUS` cannot terminate the test runner.
